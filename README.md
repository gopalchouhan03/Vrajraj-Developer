# Vrajraj Developers

The official Vrajraj Developers website, built with React, JavaScript, Vite, and Tailwind CSS.

## Requirements

- Node.js 20.19+ (or 22.12+)
- npm

## Getting started

```bash
npm install
npm run dev
```

Vite prints the local URL after the development server starts.

## Production

```bash
npm run build
npm run preview
```

## Project structure

```text
src/
  assets/images/   Local project photography
  components/      Shared navigation, footer, enquiry, map, and gallery UI
  data/            Project and company content
  pages/           Home, company, projects, and contact views
  App.jsx          Hash-based page navigation and shared layout
  main.jsx         React application entry point
  index.css        Global styles and Tailwind CSS entry point
```
